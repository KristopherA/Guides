WIREGUARD ENTERPRISE ADMINISTRATOR’S HANDBOOK CHAPTER 2 INSTALLATION AND
INITIAL CONFIGURATION

=============================================================================== 1.
OBJECTIVE
===============================================================================

This chapter covers installing WireGuard on supported Linux
distributions, creating keys, configuring the first server and client,
enabling the service, and validating a working deployment.

===============================================================================
2. SUPPORTED PLATFORMS
===============================================================================

Ubuntu 22.04 / 24.04 LTS Debian 12 Rocky Linux 9 AlmaLinux 9 RHEL 9

Windows, macOS, iOS and Android are covered in the client chapter.

===============================================================================
3. INSTALLATION
===============================================================================

Ubuntu / Debian

sudo apt update sudo apt install wireguard wireguard-tools

Rocky / Alma / RHEL

sudo dnf install wireguard-tools

Verify installation

wg –version

Expected

wireguard-tools v1.x.x

===============================================================================
4. GENERATE KEYS
===============================================================================

Create a secure directory

sudo mkdir -p /etc/wireguard cd /etc/wireguard

Generate keys

wg genkey > private.key wg pubkey < private.key > public.key

Protect the private key

chmod 600 private.key chmod 600 /etc/wireguard/*.conf

===============================================================================
5. FIRST SERVER CONFIGURATION
===============================================================================

/etc/wireguard/wg0.conf

[Interface] Address = 10.100.0.1/24 ListenPort = 51820 PrivateKey =
SERVER_PRIVATE_KEY SaveConfig = false

[Peer] PublicKey = CLIENT_PUBLIC_KEY AllowedIPs = 10.100.0.2/32

===============================================================================
6. FIRST CLIENT CONFIGURATION
===============================================================================

[Interface] Address = 10.100.0.2/24 PrivateKey = CLIENT_PRIVATE_KEY DNS
= 10.60.40.10

[Peer] PublicKey = SERVER_PUBLIC_KEY Endpoint = vpn.example.com:51820
AllowedIPs = 10.60.10.0/24,10.60.20.0/24 PersistentKeepalive = 25

===============================================================================
7. START THE SERVICE
===============================================================================

sudo systemctl enable wg-quick@wg0 sudo systemctl start wg-quick@wg0

Verify

systemctl status wg-quick@wg0

===============================================================================
8. ENABLE FORWARDING
===============================================================================

Temporary

sysctl -w net.ipv4.ip_forward=1

Permanent

echo “net.ipv4.ip_forward=1” >> /etc/sysctl.conf sysctl -p

Verify

cat /proc/sys/net/ipv4/ip_forward

Expected

1

===============================================================================
9. INITIAL VALIDATION
===============================================================================

Show status

wg

Show routes

ip route

Check listener

ss -lunp | grep 51820

Ping VPN peer

ping 10.100.0.2

If the handshake succeeds but traffic fails: - Verify AllowedIPs -
Verify IP forwarding - Verify firewall rules - Verify routing

===============================================================================
10. COMMON INSTALLATION ISSUES
===============================================================================

Problem: Service will not start Check: - Syntax in wg0.conf - File
permissions - Private key format

Problem: No handshake Check: - UDP/51820 firewall - Endpoint DNS -
Public/private keys

Problem: Handshake but no traffic Check: - Routes - NAT - FORWARD
rules - Reverse routing
