**Updated Complete Step-by-Step Guide: Fixing Sonos App Not Accessing iTunes / Music Library on Mac**

This guide consolidates **all previously tried steps** with the client (2023–2026) and now includes the detailed GUI method for resetting the Sonos app’s Local Network permission on macOS (especially important for Sequoia and later).

### Previously Tried Steps (Summary)
- Full system restarts and Sonos power cycles (multiple times).
- File Sharing setup on Mac (repeated).
- SMB protocol fix via `/etc/nsmb.conf` (worked for Error 913).
- Adding/re-adding library in Sonos app (Mac + iPhone).
- Firewall toggles.
- Network isolation checks.
- **New addition**: Detailed Local Network permission reset (GUI method).

### Step-by-Step Troubleshooting Guide (Do in This Order)

**Preparation**
- Ensure Mac, iPhone, and all Sonos devices are on the **same Wi-Fi network** (preferably 5 GHz).
- Note your Mac’s hostname: Apple menu → **System Settings → General → Sharing**.
- Note your username: Open Terminal and type `whoami`.

**Step 1: Restart Everything**
- Restart your Mac.
- Power cycle all Sonos units (unplug for 30+ seconds, then plug back in starting with the main unit).
- Restart your router.
- **Test** library access.  
**Note**: Tried many times — provides temporary relief but issues often return.

**Step 2: Reset Sonos App Local Network Permission (New – Highly Recommended Early Step)**
This forces the “Allow Sonos to find and connect to devices on your local network” dialogue to reappear. The GUI toggle is more reliable than Terminal commands on recent macOS.

**GUI Method:**
1. Fully quit the Sonos app (`Command + Q` or Force Quit via Activity Monitor).
2. Open **System Settings** (Apple menu → System Settings).
3. Go to **Privacy & Security** in the sidebar.
4. Scroll down and click **Local Network**.
5. Find **Sonos** in the list.
6. If the toggle is **On**, turn it **Off**. Wait 10–15 seconds.
7. Turn the toggle back **On**.
8. Re-open the Sonos app. It should now prompt:  
   **“Sonos” Would Like to Find and Connect to Devices on Your Local Network.**  
   Click **Allow**.
9. (Optional but recommended) Restart your Mac after this step.

**Note**: Repeat this after macOS or Sonos app updates.

**Step 3: Verify and Re-Enable File Sharing on Mac**
1. System Settings → **General → Sharing** → Turn **File Sharing** ON.
2. Click the info (i) → **+** to add your Music folder (`~/Music/Music` or iTunes folder).
3. Set permissions: Your account = Read & Write; Everyone = Read Only.
4. Click **Options** → Enable **SMB** and select your username.  
**Note**: Core step tried multiple times.

**Step 4: SMB Protocol Configuration**
- Open Terminal and run:  
  `sudo nano /etc/nsmb.conf`
- Add the following:  
  ```
**** this worked ****
  [default]
  client_protocols=smb3,smb2
  ```
- Save (Ctrl+O → Enter → Ctrl+X) and restart Mac.  
**Note**: Previously fixed Error 913.

**Step 5: Add/Re-add Music Library in Sonos App**
- Open Sonos app (try iPhone version first for better results).
- Go to **Manage** (or Settings) → **Music Library Settings** → **+ Add** → **Networked Device**.
- Enter path: `\\YourMacHostname\Music` (use backslashes).
- Use your Mac username and password.
- Refresh / update the library.  
**Note**: Do this **after** Local Network reset and File Sharing.

**Step 6: Firewall and Security Checks**
- Temporarily turn macOS Firewall **Off** (System Settings → Network → Firewall).
- Test, then re-enable.
- Check **Privacy & Security → Full Disk Access** and add Sonos if missing.

**Step 7: Additional / Advanced Checks**
- Verify no client isolation / AP isolation on your router.
- Reset Sonos controller in the app (if available).
- Reinstall Sonos app if issues persist.
- Test on iPhone app first, then Mac.

**Step 8: Test**
- Play individual tracks, then full playlists from the iTunes/Music library.
- Test from both Mac and iPhone.

### Order-of-Operations Notes
- Always start with restarts (Step 1).
- Perform the **Local Network reset (Step 2)** early — before reconfiguring File Sharing or re-adding the library. This is critical for local discovery and reduces recurring firewall prompts.
- Complete order: Restart → Local Network Permission → File Sharing → SMB Config → Library Re-add.
- Many of these steps (especially sharing and SMB) have been tried before but often need to be repeated **in the correct sequence** after permission resets or network changes.
