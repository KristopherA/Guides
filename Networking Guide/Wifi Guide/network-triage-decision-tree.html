Ticket intake → layer isolation → tool & playbook. Companion to the macOS Wi-Fi Troubleshooting Guide and the Network Simulation Lab Guide. Work top-down; each branch narrows the fault to one owner.

Decisive move: the wired test. If plugging into Ethernet fixes it, the fault is the Wi-Fi link or RF environment — stop looking at everything above IP. If it persists on wired, Wi-Fi is cleared.

4. When to escalate vs. advise

Fault ownerAction
RF coverage / home interferenceAdvise user (router placement, 5 GHz, Ethernet, mesh); note root cause is outside corporate control.
Auth / 802.1X / RADIUSCorrelate client log + RADIUS log; escalate to identity/network team with both timestamps.
Corporate DHCP / DNS / routing / VLANEscalate to network team with the failing command output and scope.
VPN concentrator / MTUEscalate to VPN/security team; attach underlay test proving the home link is healthy.
ISPAdvise user to contact ISP; attach traceroute/mtr showing where the path breaks.

Escalation packet (Wi-Fi guide §8): wdutil info, wdutil diagnose archive, networkQuality result, WFH script output taken while the problem occurred, and the wired-vs-wireless result.
