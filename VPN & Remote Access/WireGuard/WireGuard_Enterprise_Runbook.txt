===============================================================================
INSTALLATION
===============================================================================

Ubuntu

sudo apt update sudo apt install wireguard wireguard-tools

Enable service

sudo systemctl enable wg-quick@wg0

Start

sudo wg-quick up wg0

Status

sudo wg ip addr ip route ss -lunp | grep 51820

===============================================================================
KEY MANAGEMENT
===============================================================================

Generate keys

wg genkey > private.key wg pubkey < private.key > public.key

Recommendations - One keypair per device. - Store private keys with 600
permissions. - Rotate keys annually or after compromise. - Remove stale
peers promptly.

===============================================================================
IPTABLES COOKBOOK
===============================================================================

Allow VPN

iptables -A INPUT -p udp –dport 51820 -j ACCEPT iptables -A INPUT -i wg0
-j ACCEPT

Forward

iptables -A FORWARD -i wg0 -j ACCEPT iptables -A FORWARD -o wg0 -j
ACCEPT

Masquerade

iptables -t nat -A POSTROUTING -s 10.100.0.0/24 -o eth0 -j MASQUERADE

Restrict to management VLAN

iptables -A FORWARD -i wg0 -d 10.60.40.0/24 -j ACCEPT iptables -A
FORWARD -i wg0 -j DROP

Common admin ports

22 SSH 443 HTTPS 3389 RDP 5985 WinRM 53 DNS 389 LDAP 636 LDAPS

===============================================================================
TROUBLESHOOTING DECISION TREE
===============================================================================

No handshake -> Firewall -> UDP/51820 -> DNS -> Endpoint -> Keys

Handshake but no traffic -> AllowedIPs -> Routing -> Forwarding -> NAT

Some VLANs unreachable -> Missing route -> ACL -> Internal firewall ->
Reverse routing

Slow transfers -> MTU -> MSS -> Duplex

===============================================================================
SECURITY BEST PRACTICES
===============================================================================

-   Use split tunnels for admin VPNs.
-   Restrict access with firewall policy.
-   Log VPN traffic to SIEM/Graylog.
-   Use DNS over VPN.
-   Keep peer inventory.
-   Rotate keys.
-   Disable SaveConfig in production.
-   Backup /etc/wireguard.
-   Use Dynamic DNS for roaming users.
-   Separate customer tunnels using dedicated interfaces where
    practical.
-   Periodically audit AllowedIPs for overlaps.
