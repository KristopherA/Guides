WHAT THIS IS
------------
Every tool referenced anywhere in this folder: what it does, which stage
uses it, and how to install it. Use it to answer "what was that tool called"
and "do I actually need this".

Stage column:
  0  email intake      1  URL analysis      2  document analysis
  3  verdict/handoff   L  detonation lab    H  host triage
  -  not part of the triage workflow
