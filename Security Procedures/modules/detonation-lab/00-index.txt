WHEN YOU ARE HERE
-----------------
Static triage was not enough. You need to know what a sample actually does,
which means running it — and running it safely is the entire problem this
module addresses.

Three ways to arrive:
  stage 1  a URL serves an executable, archive, or installer rather than a
           document
  stage 2  the file is not OOXML, OLE2, PDF or RTF, or static analysis could
           not resolve it
  stage 3  the verdict is malicious and behaviour is still needed

Read the safety notes at the bottom of this file before running anything in
this directory.

IMPORTANT SAFETY NOTES
----------------------
These apply to everything in this directory, without exception.

1. Do not detonate malware on your personal or work workstation.
2. Do not allow uncontrolled outbound internet access from an execution host.
   C2 callbacks trace back to whatever IP you gave them.
3. Do not run malware containers as root.
4. Use disposable infrastructure and snapshots. Assume the environment is
   burned after every run.
5. Assume live malware will attempt discovery, evasion, lateral movement,
   and C2. Design for that rather than hoping this sample is simple.
6. Do not use your home or corporate IP for a detonation environment.
7. Keep sample storage, execution, and reporting separated.

Detonation on a machine that can reach production is not analysis. It is an
incident, and it will be your incident.
