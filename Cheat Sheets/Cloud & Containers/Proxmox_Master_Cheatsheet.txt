COMMAND
  pveversion -v

DESCRIPTION
  Shows the Proxmox VE, kernel and component package versions on this node. Run it on every node; version drift is the usual cause of failed joins and migrations.

USAGE
  pveversion -v | head -5

SUCCESS
  proxmox-ve: 9.1.0 (running kernel: 6.17.2-1-pve)
  pve-manager: 9.1.1 (running version: 9.1.1/42db4a6cf33dac83)
  proxmox-kernel-helper: 9.0.4
  ceph-fuse: 19.2.3-pve1

FAILURE
  -bash: pveversion: command not found
  (You are not on a Proxmox node, or pve-manager is not installed.)

COMMAND
  qm start <vmid>

DESCRIPTION
  Starts a VM on the local node. If it fails, read the actual error rather than guessing; storage not mounted is the most common cause after a host reboot.

USAGE
  qm start 105

SUCCESS
  (no output; returns to prompt)
  qm status 105 then shows: status: running

FAILURE
  storage 'tank-vm' is not online
  (Guest disk lives on storage that is inactive on this node; fix the mount with pvesm status, then retry.)

---

COMMAND
  qm shutdown <vmid> --timeout <seconds>

DESCRIPTION
  Sends an ACPI shutdown to the guest and waits. Use qm stop only if the guest ignores ACPI, since stop is a hard power-off.

USAGE
  qm shutdown 105 --timeout 180

SUCCESS
  (no output; returns to prompt)
  qm status 105 then shows: status: stopped

FAILURE
  VM quit/powerdown failed - got timeout
  (QEMU guest agent or ACPI not responding inside the guest; investigate before using qm stop 105.)

COMMAND

DESCRIPTION
  Live-migrates a running VM to another node with no downtime. The disk must be on shared storage, or add --with-local-disks to copy it.

USAGE

SUCCESS
  2026-10-04 21:14:02 migration active, transferred 15.8 GiB of 16.0 GiB VM-state, 1.1 GiB/s
  2026-10-04 21:14:09 migration finished successfully (duration 00:00:31)
  TASK OK

FAILURE
  can't live migrate attached local disks without with-local-disks option
  (Disk is on local storage; add --with-local-disks or move the disk to shared storage. Also compare pveversion -v on both nodes.)

COMMAND

  INFO: Backup job finished successfully

FAILURE
