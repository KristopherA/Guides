15. IKEv2 VPN CONFIGURATION
------------------------------------------------------------

GUI:
VPN -> IPsec

------------------------------------------------------------
STEP 1 — ENABLE IPSEC
------------------------------------------------------------

VPN -> IPsec -> Tunnels

Enable:
[x] Enable IPsec

------------------------------------------------------------
STEP 2 — CREATE PHASE 1
------------------------------------------------------------

VPN -> IPsec -> Tunnels -> Add P1

Settings:
Key Exchange Version:
IKEv2

Internet Protocol:
IPv4

Interface:
WAN

Authentication:
Mutual PSK or Certificates

Encryption:
AES256-GCM

Hash:
SHA256

DH Group:
14 or higher

Lifetime:
28800

------------------------------------------------------------
STEP 3 — CREATE PHASE 2
------------------------------------------------------------

VPN -> IPsec -> Tunnels -> Show Phase 2 Entries -> Add P2

Mode:
Tunnel IPv4

Local Network:
LAN subnet

Remote Network:
Remote subnet

Encryption:
AES256-GCM

PFS:
14 or higher

------------------------------------------------------------

------------------------------------------------------------
27. BEST PRACTICES
------------------------------------------------------------

- Use MFA
- Restrict GUI access
- Use VPN for management
- Disable WAN management
- Enable IDS/IPS
- Use GeoIP filtering
- Backup before upgrades
- Keep firmware updated
- Monitor logs daily
- Use aliases extensively
- Use certificate-based VPNs
- Restrict outbound traffic where possible
